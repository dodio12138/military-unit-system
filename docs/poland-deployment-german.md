# 德军部署地域锚点

[美国陆军战史地图7](https://www.ibiblio.org/hyperwar/USA/DAP-Poland/maps/Campaign-7.jpg)标题明确为1939年9月1日04:45德军部署及首日目标，地图注明据当日德国陆军最高统帅部态势图绘制。[战史正文](https://www.ibiblio.org/hyperwar/USA/DAP-Poland/Campaign-III.html)说明第3集团军从东普鲁士向姆瓦瓦及格鲁琼兹方向推进、第4集团军由波美拉尼亚进入走廊，以及南方各集团军的大致进攻方向。

该图为历史示意地图，不是测绘成果。把图上标记按华沙、波兹南、托伦、克拉科夫、弗罗茨瓦夫和莫龙格六个地名作近似仿射地理配准；选择作战符号中心作为粗略区域参考点，统一给定35公里不确定半径。这一半径只是界面表达尺度，不是由史料测得的统计置信区间。地图图形可能不按比例，个别地点或方向误差可能更大。所有点为推定部署地域，既不是部队总部、完整部队所在位置，也不是精确前线；同一部队随时间可发生移动。团级位置如由上级推定，必须单独保留推定依据和不确定性，不能作为历史实测位置。

第1山地师图上注明稍后投入，252、257、258步兵师9月1日尚未就绪，排除前线推定。未在地图清晰辨认、且未列锚点的高级单位不应按随机地名填充。地图中的军级安排与当前模型使用的编制来源可能存在冲突；地域锚点仅表示地图符号所示地点，不改变指挥链。

最高统帅部另以[1942年美国陆军研究](https://www.ibiblio.org/hyperwar/Germany/DA-Poland/DA-Poland.html)记述的“柏林附近”为区域依据，使用柏林附近代表点和50公里地域尺度，不能理解为具体总部建筑坐标。
