# 波军1939年9月1日地域锚点

这些锚点用于展开地图，**是推定地域，不是实测坐标、总部位置或完整部队分布**。`radiusKm` 表示资料支持的粗略地域尺度，不能当作误差概率或精确作战半径；同一宽大防区的不同师共用中心仅表达资料分辨率，不能从中心判断相互距离。已有更具体地区证据的节点不在此覆盖；下级团的布点由上级地域推定时也必须标推定，并不能声称史料证明团在该点。兵力和战时编成未因画点而成为已知。

主要地理依据是[美国军情部门1942年波兰战役研究](https://www.ibiblio.org/hyperwar/Germany/DA-Poland/DA-Poland.html)：其将波美拉尼亚诸师置于托伦、比得哥什、格鲁琼兹和走廊一带；将波兹南部队置于波兹南—卡利什地区；将罗兹及部分预备部队置于维隆—罗兹—拉多姆纵深；将克拉科夫方向部队置于上西里西亚与喀尔巴阡山北麓。它是战时的概括性外国军情研究，个别番号及位置可能有误，不能作为每一单位具体点位的直接证明。[战前编成汇编](https://www.generalstaff.org/NAF/Pt_I_1939-1940/939pipa.pdf)用于判断隶属，不能证明实际到位。[波兰研究所及西科尔斯基博物馆档案](https://pism.org.uk/img/archiwum/dokumenty/B/B_I_025a.pdf)记载第27师原定经铁路至托伦预备区，但未实现，因此地图仅给走廊至比得哥什的宽泛地域，不画成已经抵达托伦。[IPN资料](https://bialystok.ipn.gov.pl/download/79/235978/Material2.pdf)称纳雷夫集群9月1日已占领防线；[J.S. Tym的研究及部署图](https://cejsh.icm.edu.pl/cejsh/element/bwmeta1.element.desklight-289fea4a-542d-45f1-aeb1-73e98d7939c4/c/BTiP_2017_3_33_kart_Tym.pdf)提供大波兰骑兵旅分散防区。

第11、22、36师及第2、3山地旅的实际开战日位置或集结仍待核实，明确排除，不把规划配属直接投到前线。第33预备师和预备集团军各部位置为宽泛防区或纵深推定，不代表已经完成集中。所有地理坐标是所描述地域的人工参考中心，不作为引用地图的精确描绘。

第14、17、25、26、2、28、30、18、3、12、13、19、29师的锚点进一步参考[美国陆军战史第7图](https://www.ibiblio.org/hyperwar/USA/DAP-Poland/maps/Campaign-7.jpg)标注的波军虚线师号，从1200像素宽原图按地理配准估算，半径设50公里。原图说明它依据德国陆军最高统帅部1939年9月1日态势图，属于德方当时对敌情的估计，尤其预备集团军各师不能由此证明已到位；数值和位置均为低置信地域参考。第10、33师等无法可靠分辨的符号保持原宽泛区域，未用德国实线兵牌代替波军。
