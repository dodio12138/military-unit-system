# 地图推定部署

地图直接展开军、师、团兵牌。原始编制数据保留未定位字段；`applyPolandDeployment` 在场景初始化时组合史料地域与上级部署，产生独立的推定坐标，缩放和布局不参与坐标计算。没有用侧栏编制代替地图兵牌。

## 依据和精度

- 德军主要军、师：从[美国陆军战史地图7](https://www.ibiblio.org/hyperwar/USA/DAP-Poland/maps/Campaign-7.jpg)的1939年9月1日04:45部署符号做粗略地理配准；不是总部建筑定位。细节见[德军依据](poland-deployment-german.md)。
- 波军：地图标示或军史记载的作战、集中地域，部分仅支持集团军大区，按实际可得证据区别说明。细节见[波军依据](poland-deployment-polish.md)。
- 下级无单独地域资料时：依上级已知／推定地域与真实隶属关系，使用固定建模规则分配位置。军、师、旅、团相对上级的最大配置距离分别为30、18、12、7公里；方位及距离由稳定ID决定，炮兵以反向配置表示后侧。**这是可编辑的部署假设，不是史料所载的阵地、行军路线或道路吸附结果。**
- 若多个单位仅有同一个宽泛地域中心，用ID决定地域内固定点，距离不超过地域尺度的22%且不超过18公里；明确标明方位为模型假设。经纬度并不具有街道级史料精度。
- 可用的概化国界面只约束相对配置保持在锚点所属大区，不能据此推断当日控制线。源锚点本身可能位于越境作战地域，不能把所有德国兵牌强制放回德国。

所有新增点均为 `positionAccuracy: inferred`，保留 `positionOriginal`、`inferenceBasis`、`inferenceAnchor`、`deploymentSources`、`inferenceRadiusKm` 与低置信标记。半径字段是表示地域的不确定尺度，不是统计置信区间或误差保证。地图用虚线框及“推”标记；悬停和属性中展示推定依据。上级汇总不会把这些点误标为核实驻地。

已存在的24个参考位置不覆盖，用户保存的手动坐标仍优先。明确未就绪、尚未抵达且没有可靠集结地域的单位排除推定，其下属也不继承前线位置，原因在属性中展示。各部所引来源时间精度不同，不能将整图解释为同一时刻的实测部署。

## 行为验证

部署纯函数不修改输入；单位数组顺序、重复初始化、缩放、平移、锁定、筛选均不改变推定点。原有地理投影、父级拖动、保存位置和撤销继续使用统一的经纬度模型。自动展开后，同一位置的指挥部兵牌连接下级真实或推定兵牌；折叠恢复总兵牌。
