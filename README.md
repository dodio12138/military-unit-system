# 兵牌编制编辑器

静态 Web 应用，直接运行，无需构建或安装依赖。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
node --test tests/*.test.cjs
```

浏览器打开 http://127.0.0.1:8765/ 。编制、预设、视图和语言偏好保存在浏览器本地。

## 示例与语言

内置四份史料示例：美国陆军第1步兵师（1944年6月诺曼底）、德国陆军第1步兵师（1939年9月波兰战役）、八路军总编制和新四军总编制。团级及以上番号与主官依据史料，营以下编成与员额为示例，均在单位说明中标注。旧版的步兵连、各营和三个完整师示例在加载时从编制列表移除；步兵连和各营仍保留为整套预设，三个师的内容包含在八路军总编制中。

## 兵种标识

兵牌图形按北约 APP-6 / MIL-STD-2525 陆军标识绘制，内置 33 个兵种，包括步兵、空降、山地、两栖、特种部队、炮兵、迫击炮、火箭炮、防空、反坦克、工兵、侦察、装甲与机动、补给、维修、运输、通信、医疗、宪兵、防化等。内置兵种和自定义标识都由 `symbols.js` 中同一套图形组件 `symbolParts` 组合而成。

在「兵种兵牌」中点「新建标识」可组合图形组件、加入最多 4 个字符的文字（如 MP、UAS）并设定默认级别，保存后作为新兵种出现在兵牌库、单位属性和预设中；拖入时按默认级别带基础编制。自定义标识保存在本浏览器。删除标识时，使用它的单位和预设改为通用兵牌；找不到定义的兵种只显示空白兵牌框，不会改写已保存的数据。

顶栏「?」打开使用说明，介绍放置、展开与叠牌、人数汇总、预设、自定义标识、导出和快捷键。

界面支持英文与中文，默认英文，顶栏按钮切换。中文是源语言：界面文字和内置数据以中文书写并作为词条键，英文显示时由 `t()`（界面）与 `tr()`（数据名称）翻译，不改写已保存的编制。用户自填的名称原样显示。英文兵牌标签和预设明细过长时使用美军标准缩写（如 Bn、Co、Plt、Inf、Arty），属性面板和提示框中显示全称。内置参考图的布局按当前语言的标签宽度重新整理，手动调整过的布局保留。

## 在线版本与部署

Pages 启用后的访问地址：https://dodio12138.github.io/military-unit-system/

`.github/workflows/pages.yml` 在推送到 `main` 或手动运行时执行测试；通过后，仅将 `index.html`、`src/` 和 `assets/` 打包部署到 GitHub Pages，并自动给页面引用的 CSS / JS 加上提交哈希作为版本号，避免浏览器使用旧缓存。仓库的 Pages 发布源使用 GitHub Actions。

线上页面与本地页面的浏览器存储各自独立，本机已保存的编制不会自动出现在在线版本中。

## 代码结构

- `index.html`：工作台、属性面板与对话框。本地开发时 `?v=` 版本号无需手动修改，部署时自动替换。
- `src/core/i18n.js`：语言选择、界面词条 `t()`、数据名称翻译 `tr()` 与静态页面本地化。
- `src/core/config.js`：存储键、示例标识和编辑限制。
- `src/data/presets.js`：编制模板、装备岗位、人数与装备汇总，以及新四军直属部队示例。
- `src/data/examples.js`：美军、德军步兵师与八路军、新四军示例图，以及仍用作整套预设的营、师模板。
- `src/data/migrations.js`：旧保存数据的一次性升级，保留升级版本以免覆盖后续编辑。
- `src/render/symbols.js`：图形组件、兵种、级别、自定义标识注册、SVG 兵牌与厚度侧面绘制。
- `src/render/projection.js`：全画布投影矩阵、逆变换与边界计算。
- `src/render/view-mode.js`：平面 / 2.5D 切换和独立保存的显示偏好。
- `src/editor.js`：画布交互、编制树编辑、折叠与叠牌、撤销、属性编辑、保存和导出。
- `assets/styles/`：工作台布局及 Pixel HUD 适配。
- `assets/hud/`：第三方样式、字体及许可证。
- `tests/`：人数、装备、旧图升级、兵种标识和双语词条覆盖的回归测试。

目前按 `index.html` 中的顺序使用 `defer` 脚本加载，各文件共享经典脚本作用域；数据与绘制文件不主动启动编辑器，事件绑定及初始化由编辑器完成。后续迁移到 ES modules 时需将共享状态改为显式参数或导出接口。

## 拓展约定

新增装备先定义 `equipmentKinds` 中的计量单位及固定乘员岗位，再添加 SVG 兵牌类型和预设。单件装备本身计一件，乘员直接记在该兵牌内；上级通过 `presetStats` / `strengthOf` 汇总，不能再额外添加一份乘员子节点。

完整编制引用模板快照。改变内置模板后，需要同步已有图时，在 `migrations.js` 中新增有版本标记的一次性升级，并验证折叠、叠牌和重新加载前后的数量一致。

2.5D 使用两条地面轴等长、与水平线成 30° 的等距投影。网格、连线、标签和兵牌一起改变视角；兵牌平放在地面上，厚度沿屏幕竖直方向延伸。切换视图不修改编制树、坐标或人数；拖动和放置通过逆矩阵返回模型坐标，SVG 导出对整张编制图应用同一投影。

示例中补充的下级编成、装备和定员用于编辑演示，标注为示例或推定。

新增界面文字用 `t("中文原文")` 并在 `src/core/i18n.js` 的 `uiMessages` 中补英文；新增内置数据名称在 `dataTerms` 中补英文，或使用已有的番号、兵种 + 级别规则。`tests/i18n.test.cjs` 会检查漏译的界面词条。
